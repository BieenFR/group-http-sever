# Checklist nội bộ — chưa phải mẫu chính thức của môn

Phải đối chiếu https://stevens.netmeister.org/631/checklist và https://stevens.netmeister.org/631/hw trước khi nộp; chưa đọc được hai trang này khi chuẩn bị.

- [ ] Code hoàn chỉnh, không còn stub ENOSYS/TODO chức năng bắt buộc
- [ ] GET/HEAD; nhận HTTP/1.0 và 1.1; trả HTTP/1.0
- [ ] Headers, status, If-Modified-Since và binary transfer
- [ ] Tất cả flags -d -h -c -i -l -p và document root
- [ ] Daemon, nhiều kết nối, debug tuần tự; không stdout ở chế độ thường
- [ ] Directory listing, ~user, CGI theo RFC3875, logging
- [ ] NetBSD 11.0, Linux và OmniOS đều được build/chạy thật
- [ ] Hoàn thành ma trận docs/REQUIREMENTS.md
- [ ] README có hướng dẫn build/run và tổng kết đóng góp thực tế
- [ ] Mỗi người có đóng góp tương đương và lịch sử Git thật
- [ ] Makefile, source, README, checklist, git log có trong tar
- [ ] Tên tar và thư mục giải nén dùng đúng usernames
- [ ] Xác nhận múi giờ hạn nộp và cách nộp của lớp
